## Como rodar no VS Code

1. Extraia o ZIP.
2. Abra a pasta no VS Code.
3. Clique com o botão direito no arquivo `index.html`.
4. Se tiver a extensão Live Server, clique em **Open with Live Server**.
5. Se não tiver, abra o `index.html` direto no navegador.

## Como adicionar novos projetos

No `index.html`, procure pela seção:

```html
<section class="section" id="projetos">
```

Copie um bloco `<article class="project-card">...</article>` e altere:

- Nome do projeto
- Descrição
- Tecnologias
- Link do GitHub
- Link da demonstração

## Como publicar no GitHub Pages

1. Crie um repositório no GitHub.
2. Envie os arquivos do projeto.
3. Vá em **Settings**.
4. Clique em **Pages**.
5. Em **Branch**, selecione `main`.
6. Clique em **Save**.
7. O GitHub vai gerar o link do seu portfólio.
